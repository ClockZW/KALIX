# Kalix Aluminium

Website for **Kalix Aluminium** — aluminium and glass, *strength in every form*.
192 Munhondo Rd, Ruwa · +263 772 544 246 · +263 712 176 089

Live at https://kalix-scif.onrender.com (Render static site, auto-deploys on every push to `main`).
Also still on Netlify at https://kalixaluminium.netlify.app, which some phones/networks fail to open.

Static one-page site (no build step): `index.html` plus `assets/` (css, js, img).
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

The quote form opens WhatsApp (+263 772 544 246) with the customer's message filled in.
